# آموزش کامل فیچرهای جدید Hermes-Pocket (پورت Triad)

این نسخه سه حالت الهام‌گرفته از Triad AI را به Hermes-Pocket اضافه می‌کند: **Aether**، **Harness** و **Server Profiles** — به‌علاوه **ورودی صوتی** و **خروجی Markdown**. همه‌چیز نیتیو (Kotlin/Compose)، بدون WebView.

---

## ۱. Aether — چت مستقیم با مدل، بدون سرور

**مسیر:** Control Center → کاشی «Aether / اتر»

Aether اپ را از سرور Hermes مستقل می‌کند: مستقیم به API هر پرووایدر LLM وصل می‌شوید و چت می‌کنید.

### راه‌اندازی
1. وارد صفحه Aether شوید؛ بار اول خودکار صفحه تنظیمات باز می‌شود.
2. یکی از ۱۳ پیش‌تنظیم را انتخاب کنید:
   - OpenAI، Anthropic، Google Gemini، OpenRouter، Groq، DeepSeek، Together، Mistral، xAI، Nous، Ollama، LM Studio، Custom
3. **Base URL** و **API key** را وارد کنید (برای Custom هر اندپوینت OpenAI-compatible مثل api.xkiro.com).
4. دکمه 🔁 (Refresh) را بزنید تا لیست مدل‌ها از `/models` خوانده شود؛ یک مدل انتخاب کنید یا دستی تایپ کنید.
5. **Save** → تمام.

### امکانات
- **استریم زنده:** پاسخ توکن‌به‌توکن نمایش داده می‌شود (SSE برای هر سه پروتکل: OpenAI، Anthropic Messages، Gemini).
- **دکمه Stop:** وسط تولید می‌توانید متوقف کنید.
- **Temperature و Max tokens:** با اسلایدر در تنظیمات.
- **System prompt:** اختیاری؛ به ابتدای هر مکالمه تزریق می‌شود.
- **چند مکالمه:** هر چت جداگانه ذخیره می‌شود (فایل JSON در فضای خصوصی اپ)؛ از لیست باز یا حذف کنید.
- **خروجی Markdown:** دکمه ⬇️ در نوار بالا مکالمه فعلی را به `Documents/Aether/` (پوشه اختصاصی اپ) خروجی می‌گیرد.
- **ورودی صوتی:** دکمه میکروفون کنار فیلد متن؛ با SpeechRecognizer اندروید (fa-IR برای دستگاه فارسی).

## ۲. Harness — ایجنت روی دستگاه با ابزار لوکال

**مسیر:** Control Center → کاشی «Harness / هارنس»

Harness یک حلقه ایجنتی است: مدل می‌تواند **tool call** بفرستد و اپ ابزارها را لوکال اجرا می‌کند و نتیجه را به مدل برمی‌گرداند — تا وقتی جواب نهایی متنی تولید شود.

### راه‌اندازی
1. وارد Harness شوید؛ تنظیمات را باز کنید.
2. اگر قبلاً Aether را پیکربندی کرده باشید، همان Base URL/Key/Model پیش‌فرض پر می‌شود — فقط Save کافی است.
3. مدل باید function calling پشتیبانی کند (اکثر مدل‌های OpenAI-compatible).

### ابزارهای لوکال
| ابزار | کار |
|---|---|
| `calculate` | محاسبه عبارت ریاضی (جمع، تفریق، ضرب، تقسیم، پرانتز) |
| `current_time` | تاریخ و ساعت فعلی دستگاه |
| `notes_save` | ذخیره یادداشت متنی روی دستگاه |
| `notes_read` | لیست/خواندن یادداشت‌ها |
| `http_get` | دریافت محتوای یک URL (تا ۶۴KB) |

### نمونه سوال‌ها
- «ساعت چنده؟» → `current_time`
- «۲۴۷ ضربدر ۳۸۹ چند میشه؟» → `calculate`
- «یادداشت کن: فردا قرار دندانپزشکی» → `notes_save`
- «صفحه اصلی example.com رو بخون» → `http_get`

هر اجرای ابزار به‌صورت زنده در چت نمایش داده می‌شود (کارت 🔧).

## ۳. Server Profiles — چند سرور، سوییچ سریع

**مسیر:** Control Center → کاشی «Server Profiles / پروفایل سرورها»

اگر چند سرور Hermes دارید (تست، پروداکشن، Railway، VPS):

1. دکمه **+** → نام (اختیاری)، آدرس سرور و توکن را وارد کنید.
2. هر پروفایل در لیست دیده می‌شود؛ پروفایل فعال علامت ✓ دارد.
3. دکمه «فعال کن» → تایید → اپ به سرور جدید وصل می‌شود. چت فعلی حفظ می‌شود.
4. دکمه سطل زباله پروفایل را حذف می‌کند.

پروفایل فعال دقیقاً همان اتصال سرور اصلی اپ است — یعنی Runtime Setup هم همگام می‌ماند.

## ۴. نکات امنیتی

- کلیدهای API فقط در SharedPreferences خصوصی اپ ذخیره می‌شوند؛ هرگز لاگ نمی‌شوند.
- اگر قفل بیومتریک فعال باشد، دسترسی به UI (و در نتیجه Aether/Harness) هم پشت آن قفل است.
- `http_get` در Harness فقط http(s) می‌پذیرد و به ۶۴KB محدود است.

## خلاصه تغییرات فنی
- `aether/`: کلاینت سه‌پروتکله + استریم SSE + کشف مدل + مخزن مکالمات
- `harness/`: حلقه ایجنتی function-calling + ۵ ابزار لوکال + ارزیاب ریاضی
- `ServerProfileStore`: پروفایل‌های چندسرور + سوییچ
- `SpeechToTextHelper`: ورودی صوتی
- ناوبری: مسیرهای `aether`، `harness`، `profiles` در NavHost + کاشی‌ها در Control Center
